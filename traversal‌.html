Python 的“遍历”之旅 🚇

同学们，在 Python 里，把很多东西装在一起叫列表(list)，比如把6个地铁站装成一个列表。
用 for 循环把列表里的东西一个一个拿出来，不跳过、不重复，这就叫遍历！
点击“开始遍历”，一边看地铁跑，一边看下面的 Python 代码是怎么一句一句运行的吧～
# 这就是遍历列表的 Python 代码，看它一句一句地运行 👇
stations = ["望京西站", "人民广场站", "公园站", "学校站", "游乐园站", "未来城站"]
for station in stations:
print(station) # 到达这一站
每一次循环，变量 station 就会拿到列表里的一个值：
station = 还没开始
💻 Python 控制台输出（print 打印的内容）：
当前进度：0/6
准备好开始地铁的遍历之旅啦！先点“下一步”，看看 for 循环怎么一步一步走～

🛠️ 试一试：换成你自己的站点

遍历不只能走地铁站，它能把任何列表一个一个走完。
每一行写一个站点名字，改完点“换上我的列表”，再点“下一步”看看变化。想一想：如果你写 8 个站，for 循环会走几次？


🎉 遍历完成啦！

for station in stations: 把列表里的站点一个一个取出来，每取一个，变量 station 就换成那一站，再用 print 打印一次，一个不落——这就是 Python 的“遍历”！
记住口诀：for 循环 = 一个一个拿，不跳过、不重复、不遗漏。
